# 🚗 Hyundai BSD City — Official Dealer Website (Frontend Project)

Modern, fast, and conversion-focused dealer website built using **pure HTML & CSS**.
Designed to simulate a real-world automotive dealership landing page with strong SEO structure and lead-generation UI.

## 🔥 Project Overview

This project is a fully responsive promotional and company profile website for an official Hyundai dealership.
Built to demonstrate **clean frontend architecture, semantic HTML, performance optimization, and SEO awareness** — without relying on frameworks.

> Goal: Create a production-ready dealership website using only HTML & CSS while maintaining professional UI/UX and search visibility.

## ✨ Key Features

- Responsive layout (desktop, tablet, mobile)
- Modern automotive dealership UI
- SEO-optimized meta tags & structured data
- Promo landing page with conversion-focused sections
- Image gallery for monthly promotions
- Clean semantic HTML structure
- Lightweight & fast loading (no framework dependency)
- Ready for deployment on static hosting

## 🧠 Technical Highlights

**Frontend:**

- HTML5 semantic structure
- CSS3 (Flexbox & Grid)
- Custom responsive layout
- Optimized font loading & assets

**SEO & Performance:**

- Meta & OpenGraph optimization
- Structured data (JSON-LD schema)
- Fast load & lightweight assets
- Mobile-first layout
